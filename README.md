# MyFirstGame — Pixel Rogue: Dungeon of the Ancients

Олдскульный 2D Action Roguelike с процедурной генерацией подземелий, пиксельной графикой, процедурным 8-битным чиптюн-саундтреком и звуковыми эффектами, готовый к запуску на ПК, публикации в Steam и Google Play Market.

---

## 🕹 Управление

| Действие | Клавиатура + Мышь | Геймпад (Xbox / PS) | Сенсорный экран (Android) |
|---|---|---|---|
| **Движение** | `W`, `A`, `S`, `D` или Стрелки | Левый стик | Виртуальный аналоговый стик |
| **Прицеливание** | Курсор мыши | Правый стик / Направление | Автонаведение / Стик |
| **Атака / Стрельба** | Левая кнопка мыши (ЛКМ) | Кнопка `X` / Правый триггер (RT) | Сенсорная кнопка `ATK` (Меч) |
| **Кувырок / Дэш** (с неуязвимостью) | `Space` (Пробел) или ПКМ | Кнопка `A` | Сенсорная кнопка `DASH` |
| **Взаимодействие** (Сундуки / Лестницы) | `E` или `F` / Клик | Кнопка `Y` | Сенсорная кнопка `USE` |
| **Свиток магии** (Метеоритный дождь) | `Q` или `E` | Кнопка `B` | Сенсорная кнопка `SPELL` |
| **Пауза** | `Escape` или `P` | Кнопка `Start` / `Menu` | Сенсорная кнопка `||` |
| **Полноэкранный режим** | `F11` (или в Меню Настроек) | Меню Настроек | Автоматически |

## ⚔️ Особенности игры

1. **Процедурные подземелья**: Случайная генерация залов, коридоров, комнат с сокровищами и арены финального босса (Этажи 1–4).
2. **Аутентичный ретро-вид**: Низкополигональный буфер 480×270 с целочисленным масштабированием без размытия, частицы пыли/крови/искр, динамическое освещение и CRT-фильтр.
3. **Чиптюн саундтрек и 8-битный звук**: 3 музыкальные темы (Меню, Подземелье, Битва с Боссом) и 10+ звуковых эффектов, генерируемых на лету без внешних файлов.
4. **Разнообразие врагов**: Прыгающие слизни, скелеты-лучники, тёмные маги, гоблины-бомбардиры, призраки, каменные големы и двухфазный босс **"Dungeon Overlord"** с bullet-hell паттернами.
5. **Дерево талантов (Meta-Progression)**: Накопление золота и перманентная прокачка 6 веток характеристик в «Алтаре прокачки» между забегами.
6. **Готовность к Steam & Google Play**: Интеграция со Steamworks (ачивки, сборщик `build_exe.py`), Google Play Games Services и конфигурация `buildozer.spec`.

## 🚀 Запуск и сборка

### Запуск из исходного кода (ПК):
```bash
python main.py
```

### Запуск мобильной версии (Google Play / Touch Simulator):
```bash
python main_mobile.py
```

### Сборка автономного `.exe` (для распространения / Steam):
```bash
python build_exe.py
```
Готовый билд появится в `dist/PixelRogue/PixelRogue.exe`.

Подробная инструкция по выгрузке в Steamworks находится в папке:
`steam_deploy/README_STEAM.md`.

Подробная инструкция по выгрузке в Google Play Market находится в папке:
`google_play_deploy/README_GOOGLE_PLAY.md`.
